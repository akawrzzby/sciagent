# 演示视频录制清单

录制顺序按答辩时的播放顺序排列。每段只演示一件事，镜头不要来回切。

## 录制前 5 分钟

1. 打开 `https://finished-editing-shore-mrna.trycloudflare.com`，**先跑一遍**要录的路径
2. 把浏览器缩放设成 100%，窗口保持 16:9 比例（或录完再裁）
3. **先点开图谱综述页的「后续研究」按钮预热**（该接口首次约 170 秒，之后走缓存 0.3 秒）
4. 问答页刷新会丢答案，所以问答那段要**先问出结果，再开始录**

## 分段清单

| # | 演示内容 | 建议时长 | 这一镜要看到 |
|---|---|---|---|
| 1 | 文献库 | 40 s | 拖入 PDF → 解析进度到 100% → 版本归并面板显示 v1/v7 判重与保留建议 |
| 2 | 阅读器 | 60 s | BERT 重排视图（真表格、KaTeX 公式）→ 切中英对照 → 悬停中文显英文 → 点 `[11]` 弹引用卡片 → 按按钮跳到参考文献并高亮 |
| 3 | 文献问答 | 90 s | 问一道跨论文题 → 展开思考过程（意图/计划/工具调用/自反馈）→ 答案里的引用可点 → 再问一个库外问题，展示拒答 |
| 4 | 图谱综述 | 60 s | 三种边视图切换 → 基石/衍生双视图 → 矛盾检测里 Attention 的 BLEU 41 vs 41.8 → 生成综述 |
| 5 | 检索推荐 | 40 s | arXiv 检索 → 结果列表 → 一键入库并解析 → 可复现性检查（仓库地址、是否可运行） |
| 6 | 写作工作台 | 50 s | 生成论文框架 → 生成 Mermaid 架构图 → CSV 转图表与图注 → 已拦截的幻觉引用列表 |
| 7 | 特色：证据链 | 50 s | 取证阶段的证据列表（每条带页码与字符区间）→ 护栏提示已移除 N 个无据引用 → 空答案即失败的提示 |

合计约 **6 分 30 秒**，落在 5–8 分钟的区间内。

## 每段录完的检查

- 画面上不出现终端、不出现本地路径、不出现任何 API Key
- 鼠标不要抖动式移动，一次点击只点一次
- 录到「等待中」的转圈超过 3 秒就剪掉，或改用已缓存的路径

## 插入 PPT

PPT 里每个功能页右侧都有虚线框（16:9）。操作：**插入 → 视频 → 此设备**，选中该段视频，然后把这个视频框拖到虚线框内对齐即可。视频与框比例一致，不会变形。

页码与内容对应：

| PPT 页 | 内容 |
|---|---|
| 8 | 功能一 文献库 |
| 9 | 功能二 阅读器 |
| 10 | 功能三 文献问答 |
| 11 | 功能四 图谱综述 |
| 12 | 功能五 检索推荐 |
| 13 | 功能六 写作工作台 |
| 14 | 特色：证据链与引用卡片 |

PPT 共 17 页：1 封面、2–3 项目背景、4–7 系统设计、8–14 功能演示、15–16 验证总结、17 致谢。
每页顶部的红色导航条会随章节高亮，插入视频不影响导航条。
